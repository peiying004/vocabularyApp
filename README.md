# VocTest — 單字與文法測驗 App

> 一款以 **Swift + SwiftUI + SwiftData** 打造的 iOS 原生學習 App。
> 使用者把單字表或文法題以 Markdown 貼上／匯入後，App 自動切批、產生四選一測驗，並針對答錯的題目做錯題複習。

---

## 專案簡介

準備 TOEIC 或英文考試時，最花時間的往往不是「找題目」，而是把題目變成能反覆自我測驗的形式。VocTest 的目標是：**貼上一段 Markdown 表格 → 立刻變成可測驗的題庫**，而且會把你答錯的題目留下來重點複習。

App 分成兩條平行的學習路線：

| 路線 | 題型 | 資料階層 |
|------|------|----------|
| **單字** | 看英文單字，四選一選出正確中文翻譯 | `Deck` → `Batch`（每 40 張）→ `Card` |
| **文法** | 填空題，四選一選出正確答案，可附詳解 | `GrammarDeck` → `GrammarBatch`（每 40 題）→ `GrammarItem` |

---

## 技術棧

| 類別 | 技術 |
|------|------|
| 語言 | **Swift 5** |
| UI 框架 | **SwiftUI**（宣告式 UI、`NavigationStack`、`List`、`Form`） |
| 資料持久化 | **SwiftData**（`@Model`、`@Query`、`@Relationship`、`ModelContext`） |
| 測試 | **XCTest**（以記憶體內 `ModelContainer` 做單元測試） |
| 建置 | **Xcode**，iOS 17.0+ |
| 架構風格 | 分層架構（Model / Parser / ReviewEngine / View），核心邏輯與 UI 解耦 |

> 為什麼選 SwiftData 而非 Core Data？SwiftData 用 `@Model` 巨集直接把 Swift 類別宣告成持久化實體，關聯與級聯刪除（`deleteRule: .cascade`）都以型別安全的方式表達，程式碼量少、可讀性高，很適合這種階層式資料。

## 功能總覽

- 📥 **兩種匯入方式**：直接貼上 Markdown，或選擇 `.md` / `.txt` 檔匯入。
- 🧩 **容錯解析**：自動略過 YAML front-matter、標題列、表格分隔列；無法解析的行會列出行號讓使用者定位。
- 📦 **自動切批**：匯入內容依固定大小自動切成多個批次（單字與文法皆為 40），多次匯入的批次編號連續不重疊。這個數字同時是硬上限——手動新增內容時，批次滿了就不能再加，不會自動溢位到別批或另開新批。
- 📝 **四選一測驗**：干擾選項（distractor）從同批（不足時擴及同分組其他批）隨機抽取，避免「在錯的幾張之間亂猜」。
- 🔁 **答錯重練**：答錯的題目會被重新插回佇列後方，間隔幾題後再問一次，直到本輪全部答對才結束。
- 📊 **結果統計**：一輪結束顯示答對數、累計答錯次數，並列出錯題。
- 🎯 **錯題複習**：可只針對本輪錯題再測一輪。
- 🗑️ **編輯模式多選刪除**：分組、批次、單題三個層級都能多選刪除；刪除前有確認，刪光整批會自動移除空批次並將剩餘批次重新連號。
- ✏️ **匯入後就地編輯**：在預習頁點選任一列即可修改內容（單字的單字／詞性／翻譯，文法題的題目／正解／3 個干擾選項／詳解），不必刪整批重匯。修改會沿用與匯入相同的必填驗證，欄位不合法時無法儲存；累計錯誤次數與批次內順序都不受影響。
- ➕ **兩種新增方式**：預習頁的「＋」提供選單——`手動輸入一筆` 逐筆填表，`貼上 Markdown` 一次補多筆。兩者都寫進當前批次；編輯畫面內也能直接刪除該筆。
- 📌 **貼上超量由你決定**：貼進來的有效筆數超過該批次剩餘空位時，跳出確認視窗告知還能放幾筆、有幾筆放不下，讓你選「開新批次」（先填滿本批、其餘依 40 切成新批接在最後）或「放棄此次新增」（一筆都不寫）。無法解析的行照常跳過並列出行號，與超量分開呈現。
- 🆕 **批次已滿也不是死路**：按「＋」會問要不要把新內容放進新批次。選「開新批次」後同樣有手動與貼上兩條路，內容進到 deck 末端新建立的批次；原本那批完全不動。批次一律在儲存內容時才建立，不會產生空批次。
- 🔄 **重算錯誤次數**：批次首頁可把該批次所有項目的累計錯誤次數歸零，重新計算練習成效。需經確認，且只影響該批次；累計已是 0 時按鈕停用。
